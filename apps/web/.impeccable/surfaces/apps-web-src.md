# Surface brief: Coverscape web app (library + studio)

Mode: Operate. Build path: code-led (app screens). Direction pinned by the user (no concept roll).

## Direction contract

THESIS: A rehearsal tool that feels like an Edo woodblock studio at night, not a neon SaaS. Refuses the glass-and-glow dark dashboard: no blur panels, no halos, no gradients as decoration.

OWN-WORLD: Sumi-ink ground (#15120f), washi-paper text (#efe6d4), Prussian-blue ai indigo from the Great Wave, enji wine for primary actions, shu vermilion only for hanko seals and A/B marks, kincha gold for the playhead. Hairline paper borders, small radii, offset soft shadows. Shippori Mincho display + Zen Kaku Gothic New UI + JetBrains Mono for timecodes. Seigaiha wave pattern as the only texture.

STORY: Paste a link, the video opens in a bento studio; mirror, speed and A–B are each one tap; clips are kept like stamped prints in the crew's album.

FIRST VIEWPORT: Library = bento grid led by the latest video tile, a quick-clips tile and the crew's seal card with invite code; Studio = video tile dominant, wave timeline under it, controls split into speed / tramo / espejo tiles, clips column right.

SIGNATURE: The timeline is drawn as a Hokusai wave: an ink-line crest whose foam fills with indigo as the song plays; the A–B loop is a vermilion-sealed band. Mirror state stamps a 鏡 hanko on the video.

RISK: Ornament creeping into controls. Controls stay standard web controls; the world lends only type, palette, density and the wave timeline.
